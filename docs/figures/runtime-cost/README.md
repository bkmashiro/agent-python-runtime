# Runtime-cost figure

[Evidence and full report](https://github.com/bkmashiro/pysolate-spine/tree/1908514a55f524289146bad5c9b3e7a24ef5c688/experiments/runtime-cost/compare/evidence/linux-arm64-20261012).

`data.json` contains the plotted observations extracted from that report's
`summary.json`. `overview.svg` is embedded in the root README; `overview.png`
is the raster export. Both are generated by `tools/plot-runtime-cost.py`.

## Comparison

Linux arm64, 2 vCPUs, about 2 GiB RAM, no swap activity. Native uses CPython
3.14.7 with prewarming, `gc.freeze()` and a new child per request. Pysolate uses
CPython 3.14.0 and the experimental Prepared/COW runtime with INIT/EXEC separation,
pymalloc, shared engine metadata and checked poll1024. Native executes trusted
fixtures without an adversarial sandbox. These experimental optimizations are
not all integrated into the default Pysolate runtime.

- **Memory:** whole-service resident PSS slope in KiB per added instance, fitted
  separately in each repetition over N = 10, 50, 100. Fixed costs and page tables
  are excluded from this slope. Idle holds initialized instances; JSON retains
  5,000 records; Stream processes eight pages of 256 records and retains the last.
- **Throughput:** completed requests per second at concurrency 32. Short Python
  sums 32 squares; Compute sums 20,000. I/O performs three 10 ms tool calls with
  16 rows each; JSON + I/O performs two 1 ms calls with 1,024 rows each. Mixed
  uses 90% I/O and 10% Compute. Setup and warm-up are outside the timing interval.
- **Statistics:** each bar is the median of three independent runs. Whiskers show
  their observed minimum and maximum, not a confidence interval. All bars start
  at zero; native is also distinguished by hatching.

The memory and throughput panels use different workloads. The figure shows
lower marginal memory across these three resident workloads and a workload-dependent
throughput trade-off. The full report includes total PSS, CPU/request, latency,
other concurrency levels and open-loop results.

## Reproduce

From the repository root:

```sh
uv run --python 3.12 --with matplotlib==3.10.8 python tools/plot-runtime-cost.py
```

To regenerate the data snapshot from the full evidence file:

```sh
uv run --python 3.12 --with matplotlib==3.10.8 python tools/plot-runtime-cost.py \
  --summary ../pysolate-spine/experiments/runtime-cost/compare/evidence/linux-arm64-20261012/summary.json
```

No benchmark is rerun by these commands.
