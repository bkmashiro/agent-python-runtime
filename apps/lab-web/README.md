# Pysolate Lab Web v3

Latest-only, static workspace for visible Pysolate mechanism demonstrations. It intentionally does not decode the former trajectory or campaign UI schemas.

## Demos

- **Reach-gated streaming** — authored Python plus matched real-WASM baseline/streaming timelines.
- **Exact request sharing** — two identical logical requests share one measured physical execution.
- **Fail-closed source mismatch** — a different source identity receives a fresh physical execution.

The natural-cohort card is a boundary, not a performance result.

## Data pipeline

`public/lab-data/latest.json` is generated by the Go projector. It strictly validates current checked-in evidence, canonical authored source, call/physical identities, counts, and claim boundaries before producing a body-safe snapshot.

```sh
npm run data:latest
```

The browser accepts only `pysolate.lab-latest.v1`, rejects unknown fields, and never executes programs, dispatches effects, grants capabilities, or resolves private bodies.

## Development

```sh
npm install
npm run data:latest
npm test -- --run
npm run build
npm run test:e2e
npm run dev
```

The UI is static and read-only. Source text shown in the demo cards is the checked-in authored fixture source bound by the projector, not recovered private content.
