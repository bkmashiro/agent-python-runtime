## Current contract inventory

### Semantic facts

`pysolate.semantic-analysis.v3` currently exports exact source/AST/analyser/artifact/profile/import/Plan identities, positive call sites, top-level candidate regions, live-ins/live-outs, dependencies, effect summaries, barriers and rejection reasons. Candidate coverage is `module_top_level_complete`; it is not a full executable IR.

### Source-bound planner

`pysolate.source-bound-plan.v0` currently admits only `semantic_pre_dispatch` at version `pysolate.semantic-pre-dispatch-pass.v0`. Unknown pass names, versions and configurations fail closed. The planner binds decisions to verified analysis, capability Plan, source document and occurrence.

### Capability contract

Capability Plan v6 carries Host-owned schemas, grants, handler identity, effect class, read-only/idempotent flags and the current pre-dispatch contract:

- logical resource reference;
- `plan_epoch` freshness;
- unclaimed `discard_with_disposition`.

The current eligibility predicate does not yet name billing/privacy acceptance, a separate speculative-safe-when-unconsumed declaration, result byte budget or coalescing authority. These are Phase 2 gaps, not implied properties.

### Observation and lifecycle

`pysolate.staged-observation.v2` binds stream/workflow/source/call/arguments/capability/spec/handler/Plan/grant/freshness/expiry/privacy/lineage identities. Terminal states include consumed, failed, timed out, cancelled, late and orphaned. A mismatching targeted claim does not silently issue a second live call.

The streaming controller records qualified, issued and claimed events plus physical/logical/rejected counts and final-source sealing. It does not yet expose physical result bytes or billing units.

### Optimization evidence

`pysolate.workflow-boundary-observation.v0` already separates logical requests, physical executions and optimization decisions. It is currently analysis evidence with `consumer_admitted=false`; the semantic-speculation campaign must not relabel it as executable evidence without a versioned contract.

## Frozen claim boundary

Supported if the later gates pass:

- matched mechanism comparison on the frozen adversarial corpus;
- whole-program outcome, logical-call, authority and workspace parity;
- measured overlap and false-conservative critical-path time for those fixtures.

Excluded:

- production speedup;
- parity with every detail of the published EAGER implementation;
- universal Python equivalence;
- arbitrary external-write speculation;
- general Python heap transfer or persistent interpreter continuation.

## Phase 0 exit condition

Phase 0 closes only after focused/full/race/vet/Python gates pass, an exact Phase 0 Guest artifact is built and pinned privately, and the roadmap records those identities. Until then the preregistration is frozen but Phase 1 implementation must not start.
